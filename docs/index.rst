pyjsign
=======

A Python library to sign and verify JSON documents. Implements
`JSON Signature Format (JSF) <https://cyberphone.github.io/doc/security/jsf.html>`_
and `ITU-T X.590, a.k.a. JSON Signature Scheme (JSS)
<https://www.itu.int/epublications/zh/publication/itu-t-x-590-2023-10-json-signature-scheme-jss/en>`_.

See the project `README <https://github.com/spdx/pyjsign#readme>`_ for
installation, CLI usage, and conceptual documentation. This site covers
the Python API reference.
